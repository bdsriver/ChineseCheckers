# Chinese-Checkers-Frontend

A website for playing 2-6 player Chinese Checkers (Sternhalma) with AI included.

The website is available here: [https://bdsriver.github.io/ChineseCheckers/](https://bdsriver.github.io/ChineseCheckers/)

Backend repository: [https://github.com/rfboerwinkle/polaris-backend/](https://github.com/rfboerwinkle/polaris-backend/)

## Setup

Install [Node.js](https://nodejs.org/en/download) v20

Run `npm run dev` to serve webpage with hot reload

Run `npm run build` to build the webpage assets, which get put in `dist/`
